键盘按键统计 —— 免安装运行版
================================

双击 KeyCounter.exe 即可运行，无需安装 Python。

悬浮窗（默认在主屏右上角）
  · 左键拖动卡片可移动位置（支持拖到副屏）
  · 点击顶部「本次输入 / 今日输入」标题行：切换本次与今日数据
  · 点击「今日时段 / 本周节奏」卡片：切换 12 个 2 小时时段 / 7 天矩形图
    （切换时内容快速渐隐渐入）
  · 底部「不透明度」滑块：拖动调节窗口通透程度
  · 右下角圆角内侧的圆弧：长按拖动缩放悬浮窗（当前大小 ~ 2/3）
  · 右键弹出菜单，双击卡片打开完整统计界面

右键菜单功能
  · 显示主界面 / 暂停统计 / 切换迷你模式
  · 始终置顶（图标随状态变化：已置顶为普通图钉，未置顶为带斜杠图钉）
  · 切换夜间模式（夜间模式下显示为「切换日间模式」）
  · 重置缩放大小 / 开机自动启动 / 清空全部统计 / 退出
  · 检查更新：从公开的发布仓库检查新版本，确认后自动下载、校验并重启
  · 「开机自动启动」右侧有明确的开关：绿色 + 「开」表示已开启，
    灰色描边 + 「关」表示已关闭；点击即可切换

主界面
  · 左侧导航：概览 / 排行榜 / 按键明细 / 热力图
  · 内容超出时可用鼠标滚轮翻页（鼠标停在任意位置均可）
  · 左下角「检查更新」可随时检查新版本
  · 概览指标卡随统计范围变化：
      今日  -> 较昨日 / 峰值时段 / 今日各时段柱状图（12 段，每段 2 小时）
      本周  -> 日均次数 / 峰值单日 / 统计天数 + 自然周柱状图
      本月·总计 -> 日均次数 / 峰值单日 / 计数趋势弧线（不标日期）
  · 柱状图当前时段会实时累计（不必等这一段结束），并用淡色描边标出
  · 本周柱状图按自然周（周一~周日）显示，与上方日期区间一致，
    首末两列标出起止日期，每周一自动切换到新的一周
  · 柱状图：柱宽固定，4 级色阶随柱高加深，峰值用最深的绿色
  · 热力图支持 104 键 / 87 键 / 82 键三种键盘布局
  · 热力图 10 级色阶，冷暖按 7:3 分配：冷色覆盖 70% 按键，
    暖色只留给真正的高频热点，不会满屏发红
  · 左下角可切换夜间模式、清空全部统计

更新说明
  · 更新包来自公开的发布仓库，源码仓库保持私有
  · 检查更新只读取版本号与下载地址，不上传任何统计或使用数据
  · 下载完成后会校验 SHA-256，再替换程序文件；data 目录不会被覆盖
  · 只有免安装版（exe）支持自动替换；源码运行请自行更新代码

屏幕适配
  · 完整支持多显示器：菜单、悬浮窗、主界面都跟随鼠标所在屏幕
  · 支持 125% / 150% 系统缩放（不会发虚）
  · 窗口初始尺寸随屏幕自适应，最小可缩到约 880x520
  · 内容装不下时自动出现滑块，不会裁切

跨午夜说明
  · 23:50 的按键属于当天 22:00~24:00 这一格；0 点之后的按键属于新一天。
  · 所以 0 点后看「今日各时段」是新一天的数据，昨天的晚间时段仍完整保留。

统计数据保存在本文件夹的 data\ 子目录。
移动程序时请把整个文件夹一起移动。
卸载只需删除本文件夹。
