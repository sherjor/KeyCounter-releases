# KeyCounter v1.2.2

本次更新调整了悬浮窗底部的入口布局，并修复了快速点击丢失的问题。

## 新增

- 悬浮窗底部改为「不透明度」「番茄钟」两个并排入口标签，各自独立展开 / 收起；
- 两个面板可以同时展开，也可以只开一个或全部收起；
- 全部收起时右侧出现与入口同高的第三个圆角矩形，承载缩放手柄，
  三个矩形等宽铺满整行；
- 100% 缩放尺寸：仅不透明度 264×378、仅番茄钟 264×480、双开 264×544、
  全收起 264×314。

## 修复

- 快速连点同一选项卡时 Tk 只派发 `Double` 事件，导致点击丢失；
- 展开 / 收起动画尚未结束时再次点击会被动画守卫吞掉。

## 下载

`KeyCounter-1.2.2-win64.zip`（约 23 MB，解压后约 48 MB）

解压到任意目录，双击 `KeyCounter.exe`，无需安装 Python。

## 系统要求

Windows 10 / 11（64 位）。
