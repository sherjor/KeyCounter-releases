# KeyCounter v1.1.0

本次更新加入「检查更新」：程序可以直接从公开发布仓库获取新版本，不需要
GitHub 账号，也不需要手动关注发布页。

## 新增

- 主窗口左下角、悬浮窗右键菜单加入「检查更新」；
- 发现新版本后显示版本号与更新摘要，确认后下载；
- 下载完成校验 SHA-256，再替换程序文件并自动重启；
- 统计数据保存在 `data\` 目录，更新不会覆盖；
- 更新源为公开的 [`KeyCounter-releases`](https://github.com/sherjor/KeyCounter-releases)，
  源码仓库保持私有；
- 更新器优先读取最新 Release 的 `latest.json` 附件，不消耗 GitHub API 配额；
  显式支持 Windows 系统代理。

## 下载

`KeyCounter-1.1.0-win64.zip`（约 23 MB，解压后约 48 MB）

解压到任意目录，双击 `KeyCounter.exe`，无需安装 Python。

## 系统要求

Windows 10 / 11（64 位）。
