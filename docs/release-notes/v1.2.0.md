# KeyCounter v1.2.0

本次更新加入悬浮窗**番茄钟**，并做了一轮界面与性能优化。

## 新增

- 悬浮窗番茄钟：专注 25:00 / 短休息 5:00 / 长休息 15:00，三个阶段时长
  可拖动调整并记住；
- 专注期间统计本次输入，暂停不计数，倒计时结束或主动停止后显示数量；
- 收起后计时继续运行，入口右侧小绿点表示专注中（灰点表示暂停）；
- 缩放手柄常态隐藏，鼠标移入才显示；展开番茄钟时跟随到卡片右下角；
- 顶部标题点击限定在标题药丸内，标题以外的顶部区域也能拖动窗口。

## 优化

- 主窗口按需构建视图，换主题只重建当前页；
- 趋势图与柱状图按数据、尺寸、主题缓存位图，减少重复渲染；
- 写盘移出 UI 线程，长时间使用更顺滑；
- 右键菜单开关改为 4× 绘制缩小，消除边缘重影。

## 下载

`KeyCounter-1.2.0-win64.zip`（约 23 MB，解压后约 48 MB）

解压到任意目录，双击 `KeyCounter.exe`，无需安装 Python。

## 系统要求

Windows 10 / 11（64 位）。
